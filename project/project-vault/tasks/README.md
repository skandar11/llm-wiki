# tasks/ — папка на крупную задачу

Задача, не помещающаяся в строку [[../backlog|backlog]], получает папку
`tasks/<slug>/`: `spec.md` (что и зачем — читается владельцем до старта) →
`state.md` (живое состояние прогона) → `record.md` (ретро: что вышло, чему
научились). Строка в backlog остаётся и указывает сюда.
