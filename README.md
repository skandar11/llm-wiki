# LLM-wiki — шаблон личного неймспейса

Публичный шаблон личного неймспейса для жизни с ИИ-агентами. Знание живёт как
читаемый markdown в одной папке; агент (Claude Code, Codex, любой следующий
инструмент) работает поверх. Главный принцип — **LLM-независимость**: движок и
клиент сменные и выкидываемые, данные вечные.

Для кого: для человека, который хочет вести свои дела и базу — домены работы,
задачи, решения, реестры, документы — так, чтобы её одинаково понимали и он
сам (через Obsidian или любой редактор), и агент (через двери `CLAUDE.md`).

## Как начать

1. Клонировать репозиторий. **Свою копию держать приватной** (или локальной
   без remote): шаблон публичный, твои данные — нет.
2. Открыть папку целиком в Obsidian (корень = vault Обсидиана).
3. Прочитать `CLAUDE.md` (дверь неймспейса) → `meta-vault/HOME.md` (карта).
4. Заполнить `meta-vault/owner.md` (кто владелец) и пройтись по
   `meta-vault/preferences.md` (правила агенту — правь под себя).
5. Переименовать `project/` под своё первое дело и настроить его дверь по
   пометкам `<настрой>`; новые домены рождать из
   `meta-vault/vault-template.md`.

## Структура

- `CLAUDE.md` — дверь-карта неймспейса; агент подхватывает её автоматически.
- `meta-vault/` — мета-уровень: метод, решения, реестры, задачи (backlog +
  inbox), планы, люди, harness-слой (автоматизации, каналы).
- `project/` — домен-заготовка: первое дело владельца (переименуй под своё).
- `office/` — бэк-офис: юрлицо, налоги, финансы, архив документов.
- `secrets/` — доступы (вне git, никогда не коммитится).

Документы, файлы доменов и секреты в git не попадают по построению —
см. `.gitignore`.
