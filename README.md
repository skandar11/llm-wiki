# LLM-wiki — свой ИИ-агент за вечер

Шаблон личной базы для жизни с ИИ-агентом. Один агент на твоём компьютере:
знает тебя, твои дела и людей, ведёт план, пишет документы, разбирает файлы.
Помнит он не переписку, а файлы в этой папке — обычный markdown, который
читаешь и ты сам. Агент (Claude Code, Codex, любой следующий) сменный, данные
вечные.

**Гайд с нуля, 6 страниц — [guide.pdf](guide.pdf).**

## Как начать

1. **Поставить.** Подписка Claude (для начала Pro), приложение Claude для
   компьютера — [claude.ai/download](https://claude.ai/download), вкладка
   **Code**. Задачи можно ставить голосом: на Mac — дважды Fn, на Windows —
   Win+H.
2. **Дать агенту дом.** Пустая папка, например `agent`; выбрать её во вкладке
   Code.
3. **Скачать базу.** Сказать агенту:
   «Скачай в эту папку шаблон https://github.com/skandar11/llm-wiki».
4. **Собрать под себя.** Новая сессия в той же папке → **«Собери
   неймспейс»**. Агент видит, что база не собрана, и ведёт сборку сам: сначала
   разговор — кто ты, чем занимаешься, как его назвать, что делаешь каждый
   день, — потом записи под твои дела и проверка `bin/check`. Не хватает
   программ (Git, Python) — агент скажет, что поставить, и поставит после
   твоего «да».
5. **Работать.** Утром — «начинаем день», большое дело — «сделай это
   отдельной сессией», важное — «запиши», вечером — «закрываем день».

Свою копию держи **приватной** (или локальной без remote): шаблон общий, твои
данные — нет. Базу удобно читать самому в Obsidian: корень папки = vault.

## Пять правил с первого дня

1. Сначала разговор, потом запись.
2. Ни письма, ни поста без твоего «да».
3. Ничего не удаляется, только переносится в `archive/`.
4. Пароли и ключи не хранятся в файлах памяти — только в `secrets/`, вне git.
5. Результат проверяй: агент быстрый, но ошибается.

## Для агента

Вход — `CLAUDE.md` в корне. Первый запуск: в `meta-vault/structure.md` нет
даты сборки → база не собрана, первый ход — разговор с владельцем по рецепту
`meta-vault/operations/build-namespace.md`. Чистая машина — `sh bin/setup`, на
Windows — `powershell -ExecutionPolicy Bypass -File bin\setup.ps1`, после слова
владельца. Дальше: новый домен — «заведи домен под …»; новая версия шаблона —
«обнови метод».

## Что в папке

```
CLAUDE.md        памятка агента: кто он, где что лежит, правила
meta-vault/      знание и метод: канон, решения, формы, рецепт сборки
planning/        план: backlog, inbox
project/         первое дело — агент переименует под твоё
  CLAUDE.md        памятка дела
  project-vault/   знание и метод дела
  planning/        backlog дела
  docs/ inbox/     файлы — вне git
office/          бумаги и деньги: юрлицо, налоги, договоры
inventory/       руки агента: исполнители, автоматизации
archive/         сюда переезжает старое, всё — строкой в INDEX.md
bin/             установка (setup, setup.ps1) и проверка базы (check)
secrets/         доступы — вне git
guide.pdf        гайд для человека
```

Главный шов формы: **vault — это как мы делаем и что мы знаем; то, что мы
сделали и что у нас есть, лежит в папках записей рядом с vault.** Документы,
файлы дел и секреты в git не попадают по построению — см. `.gitignore`.

Версия формы — **2026-10-22** (журнал изменений —
`meta-vault/vault-template.md` §Журнал формы).
