# LLM-wiki — шаблон личного неймспейса

Публичный шаблон личного неймспейса для жизни с ИИ-агентом. Знание живёт как
читаемый markdown в одной папке; агент (Claude Code, Codex, любой следующий
инструмент) работает поверх. Главный принцип — **LLM-независимость**: движок и
клиент сменные, данные вечные.

Для кого: для человека, который хочет вести свои дела — домены работы,
задачи, решения, реестры, документы — так, чтобы базу одинаково понимали он
сам (через Obsidian или любой редактор) и агент (через двери `CLAUDE.md`).

Версия формы — **2026-10-10** (журнал изменений формы —
`meta-vault/vault-template.md` §Журнал формы).

## Как начать

1. Клонировать репозиторий. **Свою копию держать приватной** (или локальной
   без remote): шаблон публичный, твои данные — нет.
2. Открыть папку целиком в Obsidian (корень = vault Обсидиана).
3. Открыть корень в Claude Code (или другом агенте) и сказать
   **«собери неймспейс»**. Агент видит, что база не собрана, и ведёт сборку
   по рецепту `meta-vault/operations/build-namespace.md`: сначала разговор —
   кто ты, какие вопросы задаёшь каждый день, что делаешь руками, — потом
   домены под твои дела, записи, операции, проверка `bin/check`.
4. Дальше — работа: агент отвечает и записывает по операциям; новый домен —
   «заведи домен под …»; новая версия шаблона — «обнови метод».

## Структура

```
CLAUDE.md        дверь верха: карта неймспейса, агент, границы
meta-vault/      знание и метод: канон, решения, формы, рецепт сборки
bin/check        прогон проверки: связи, имена, секреты
planning/        план верха: backlog, inbox
inventory/       руки агента: исполнители, автоматизации
archive/         сток: ничего не удаляется, всё — строкой в INDEX.md
project/         домен-заготовка (переименуй под своё)
  CLAUDE.md        дверь домена
  project-vault/   знание и метод домена
  planning/        записи: backlog домена
  docs/ inbox/     файлы — вне git
office/          бэк-офис: юрлицо, налоги, деньги, бумаги
secrets/         доступы — вне git
```

Главный шов формы: **vault — это как мы делаем и что мы знаем; то, что мы
сделали и что у нас есть, лежит в папках записей рядом с vault.**

Документы, файлы доменов и секреты в git не попадают по построению — см.
`.gitignore`.
