# inbox/ — приёмник бумаг на разбор

Бумаги, приехавшие в офис (скачанные справки, присланные договоры, чеки) и
**ещё не разложенные** по корзинам `docs/`. Вне git. Режим: пустеет — не
копится; разбор — обычной сессией (файл → переименование по конвенции →
корзина в `docs/` + строка в её разделе README).
