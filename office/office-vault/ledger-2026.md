# Ledger 2026 — заработанное

Лог поступлений юрлица за год: **событие важнее итога** — итог всегда
считается из строк, а не хранится рядом. Год = файл; новый год = новый файл.

Правила:

- Запись по умолчанию **«не для налогов»**; для налогов — только по явной
  пометке владельца.
- Личные траты и переводы здесь не ведутся — только заработанное юрлицом.
- Суммы без реквизитов: номер счёта/договора — указателем на документ
  в `../docs/`.
